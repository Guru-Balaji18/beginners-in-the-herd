## Part F — Simulation-calibrated herding test

**F1.** `calibrated_test.py` builds, for each test statistic, its null
distribution from **2,000 fresh S5, kappa = 0 markets** (seed part_code
6), using the winsorized pipeline, which is how the real data were
processed.

Statistics:
- base herding: CCK t on Rm^2 (`standard_cck_regression`); WH-old t on
  Rm^3; plus each Part E variant once it exists;
- g5: the t on Post x High in the **primary Step 5 design**
  (`main_regression.design`, dummy form, controls for CCK, NW(5)), with
  the real entry-index High/Low dummies and real control calendar on the
  simulated days;
- g7 (Post x Low) is recorded the same way.

Calibrated one-sided p = share of null t-statistics <= the observed t.
"Flags herding" = calibrated p <= 0.05, i.e. t <= the null's 5th
percentile.

**F2. Validation on held-out markets** (seed part_code 7, never used to
build the null):
- **Size:** 1,000 S5, kappa = 0 markets. Target 3.6–6.4%.
- **Power:** 1,000 S5 markets at each kappa > 0 (common random numbers
  across kappa). Detection rate of the calibrated vs the textbook
  (t < -1.645) test.
  - Herding strength is constant over time in every simulated market,
    so **g5 and g7 are true nulls at every kappa**. For them the "power"
    row is really a false-alarm rate at each kappa and is reported as
    such.
- **Mismatch:** 1,000 S2 and 1,000 S4 kappa = 0 markets, judged against
  the **S5** null. Their false-alarm rate shows how much the calibrated
  test depends on the simulation being realistic.

**F3.** Apply to the real data: calibrated p for base herding (CCK,
WH-old, Part E variants) and for g5 (CCK, WH-old).

**F4. Outputs:**
- `results/calibrated_test_results.csv`;
- `results/calibrated_null_distributions.png`: one panel per statistic,
  null histogram with the real value marked;
- `results/calibrated_size_power.csv`: textbook vs calibrated.

**Interpretation, fixed now:**
- If held-out size is in the band **and** the mismatch false-alarm rates
  in S2 and S4 are also in the band, the calibrated test is robust. Its
  real-data p-values are our preferred inference.
- If the mismatch rates fall outside the band, the calibrated test is
  only as good as S5 is realistic. Real-data calibrated p-values are
  then reported as conditional on S5, and we say plainly that they
  depend on the scenario.
- **Expectation stated before running:** in Part B, CCK's null median t
  was +1.1 in S5 but -7.2 in S4. We therefore expect the S5-calibrated
  CCK test to false-alarm on almost every S4 market, meaning a strong
  dependence on the scenario.
- Calibrated power of WH-old is expected to be low: in Part B, its
  median t barely moves with kappa (-8.3 at kappa = 0, -8.7 at
  kappa = 100).

## Part G — Explain the two strange behaviors

**G1. Winsorization false alarms.** One S1, kappa = 0 market (Part B
seed, rep 0), with R built unwinsorized and then clipped at the pooled
0.1/99.9 percentiles, exactly as in Part B.
- Report the share of stock returns clipped, by |R_m,t| decile (big-move
  days vs quiet days).
- Report CSAD before vs after clipping, by |R_m,t| decile, as the %
  reduction.
- Figure `results/mech_winsorization.png`:
  - (left) share clipped vs |R_m,t|;
  - (right) CSAD vs |R_m,t| before and after clipping, with fitted CCK
    curves.
- **Per-day (cross-sectional) winsorization:** each day's returns are
  clipped at **that day's** 0.1/99.9 percentiles.
  - Size check: S1 and S5, kappa = 0, 1,000 markets each, Part B seeds.
  - The false-alarm rate is compared with Part B's pooled and
    unwinsorized results.
- Expectation: on big days the whole cross-section shifts by about R_m,
  so a shared pooled cutoff clips a large share of that day's stocks
  toward one value. That shrinks dispersion exactly on big days, which
  CCK reads as herding. Per-day clipping should not do this.

**G2. CCK's non-monotonic power.** One S1 market (Part B seed, rep 0,
unwinsorized, so G1 doesn't confound it) at kappa = 0, 100 and 3000.
- Figure `results/mech_cck_nonmonotonic.png`: CSAD vs R_m,t with the
  fitted CCK curve, plus the coefficient table.
- Expectation: CSAD is proportional to h = 1/(1 + kappa R_m^2). That
  curve is concave in |R_m| only up to its inflection at
  |R_m| = 1/sqrt(3 kappa) and convex beyond it:
  - kappa = 100: inflection at 5.8%, so almost all days sit on the
    concave part and CCK sees herding;
  - kappa = 3000: inflection at 1.05%, so most big days sit on the
    convex, flattening tail. The fit then puts a strongly negative
    |R_m| coefficient and a positive R_m^2 coefficient on them.

**G3.** `docs/mechanisms.md`: one plain-English paragraph per mechanism,
for judges.

## Part H — Fix the standard errors

**Stated beforehand.** In D3, the plain Post x Rm^2 term, which involves
**no** entry index, already had null t SD of about 2. So a persistent,
forward-filled entry index cannot be the whole explanation. We also
expect heavy-tailed R_m (a few extreme, clustered days dominate the
estimate) and misspecification of the CSAD–R_m curve to contribute.
Longer HAC lags or a block bootstrap may or may not fix that. This is
what H2 tests.

**H1. Methods** (new module `robust_se.py`; existing code unchanged):
- NW(5), the current method, as the baseline;
- NW(21), NW(63), NW(126): Newey-West/Bartlett with those maximum lags;
- **moving-block pairs bootstrap:**
  - rows (y_t, x_t) resampled jointly in 21-day blocks, no wrap-around,
    series length T;
  - SE = standard deviation of the bootstrap coefficients;
  - t = coefficient / bootstrap SE, one-sided normal critical value
    -1.645;
  - 5,000 replications on real data.

**H2. Validation in simulation:**
- 1,000 S5, kappa = 0 markets per winsorization setting (winsorized and
  unwinsorized), seed part_code 8.
- Terms: the D3 Post terms (CCK Rm^2 x Post, WH Rm^3 x Post) and g5 and
  g7 in the primary design (CCK and WH).
- Every method is computed on the same markets. Each term is a true
  null, so the target false-alarm rate is 5% (band 3.6–6.4%).
- The bootstrap uses **B = 999** per simulated market (the feasible
  subset). If that doesn't finish in about 3 hours on 12 workers, the
  number of markets is reduced to 500, logged as a deviation.
- **Best-calibrated method** = the one with the smallest mean absolute
  distance from 5% across the four **winsorized-pipeline** cells
  (Post-CCK, Post-WH, g5-CCK, g5-WH). Ties are broken on the
  unwinsorized cells.
- If no method puts all four winsorized cells inside 3.6–6.4%, we say
  that no tested SE method is calibrated. We still report the best one,
  and point to Part F's calibrated test as the better inference for g5.

**H3. Real data:**
- (i) Primary specification with the best-calibrated method (5,000
  bootstrap replications if it is the bootstrap): g5 and Post x Low for
  CCK and WH, next to the NW(5) numbers.
- (ii) Robustness: rebuild the real panel with **per-day**
  winsorization, in place of pooled.
  - Start from the unclipped returns reconstructed as in D2.
  - Clip each day at that day's 0.1/99.9 percentiles.
  - Recompute the equal-weighted market return.
  - Rerun `main_regression.run` (all 25 variants, NW(5), as in Step 5),
    plus the primary spec with the best-calibrated method.
  - Output `results/step5_daywins_results.csv`.

**H4. Placebo update:**
- The placebo decision in Part C ranks g5 **coefficients**, which don't
  depend on standard errors, so it cannot change.
- Rerun with the best-calibrated method:
  - the share of placebo dates with "significant" g5;
  - the year-FE decisions (C6), which use p-values;
  - the plan-literal check;
  - the Holm table.
- Report whether any decision changes. Save as new files
  (`results/partC_summary_H.json`), keeping the originals.

**What outcomes mean:**
- A method that is calibrated in H2 and still finds g5 < 0 at p < .05
  on real data would be the strongest remaining support for H1. It would
  still face Part C (placebo and year FE), which it can't overturn.
- If g5 loses significance under calibrated SEs, the Step 5 result was
  an artifact of NW(5) standard errors that are too small.
- If per-day winsorization changes the sign or significance of g5, the
  Step 5 result depended on the cleaning step.
